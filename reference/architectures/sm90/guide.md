# Hopper / SM90

H100/H200 runtime CC is **9.0**. The shared diagnostic workflow and candidate metrics remain available. Confirm WGMMA/TMA instruction requirements and the compiled target separately; WGMMA uses a different execution/accumulation model from SM100 tcgen05/TMEM.

This profile provides conservative common metrics and target routing, not a newly validated Hopper collector pairing. Query the installed NCU and the report's actual fields. Do not load SM100 programming advice for Hopper solely because a historical reference compares the two. See [validation](../../validation.md).

Sources: [GPU CC](https://developer.nvidia.com/cuda/gpus), [Hopper tuning](https://docs.nvidia.com/cuda/hopper-tuning-guide/index.html).
